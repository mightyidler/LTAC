![LTAC — LG TV Auto Control](Main.png)

LG webOS TV를 PC 모니터처럼 쓰기 위한 Windows 앱입니다. PC의 전원과 화면 상태에 맞춰 TV를 자동으로 켜고 끕니다.

[Windows 다운로드](https://github.com/mightyidler/LTAC/releases/latest)

![LTAC 연결 데모](docs/media/ltac-demo.gif)

[데모 원본 화질로 보기](docs/media/ltac-demo.mp4)

## 사용 방법

1. 설치 파일을 실행합니다. 관리자 권한이 필요합니다.
2. PC와 TV를 같은 네트워크에 연결하고, LTAC에서 TV를 선택합니다.
3. TV에 표시되는 연결 요청을 승인합니다.

TV를 자동으로 켜려면 TV 설정에서 네트워크를 통한 전원 켜기 기능을 활성화해 주세요.

앱에서 절전 단축키를 지정하면 PC와 TV를 함께 절전 상태로 전환할 수 있습니다.
