## 새 전원 서비스 회귀 테스트

로컬 임의 포트의 모의 WebSocket과 임시 설정 파일만 사용합니다. 실제 TV 주소·사용자 설정·서비스를 변경하지 않습니다.

1. 두 TV에 OFF를 병렬로 전송하고, 한 TV 응답이 다른 TV 수신에 의존해도 완료.
2. 전송 후 응답 대기 시간 초과에도 OFF 표식 유지. 중복 OFF를 재전송하지 않음.
3. 절전 OFF가 약 1.4초 예산 안에 종료.
4. 여러 인증 소켓 중 어느 TV의 종료도 폴링 없이 감지.
5. 화면 OFF debounce 중 취소하면 기존 연결 보존, Active 재확인 후 WoL 생략.
6. 자동 동기화 OFF와 유지보수 복귀에서 ON 예약하지 않음.
7. 잘못된 키·중복 기기·16대 초과 설정 거부.
8. machine DPAPI 내보내기가 물리적 wake 검증 여부를 바꾸지 않으며, 재암호화되어도 같은 기기 설정으로 식별.
9. 직접 입력 후 검색으로 같은 TV를 다시 저장하면 기존 행 갱신. 최대 기기 수에서 기존 기기 갱신 허용.

기존 코어 테스트는 WoL 패킷 형식·루프백 UDP, 상태 전이·중복 이벤트, Win32 알림 등록/해제, 계정 DPAPI 저장, 페어링 승인·거부·키 재사용, SSAP 오류·응답 제한시간을 검사합니다.

### JSON 원본 기준 font weight 재적용

- 이전 작업 코드의 weight 보존 대신 사용자 첨부 JSON 원본을 기준으로 전면 재생성. 원본 Regular 400 → 300, Medium 500 → 400, SemiBold 600 → 500을 한 번만 적용.
- `tools/import-typography.mjs`가 원본 노드에서 26개 규칙을 추출해 `ui/src/typography.css`와 원본 경로·원본/최종 weight·SHA-256을 기록한 `typography.json` 생성. 동일 원본을 다시 가져와도 파일 hash가 바뀌지 않음.
- 메뉴 500 보존이라는 앞선 예외는 폐기. JSON의 정보 수정·삭제는 Medium이므로 최종 400. 단축키 입력/저장·업데이트 중의 인라인 font도 최종 토큰을 읽음.
- 한국어·영어·일본어 × 라이트·다크에서 화면별 computed weight를 원본 대응표와 대조. 단축키 capture와 메뉴 포함. 입력 모션 테스트 및 build 통과.
